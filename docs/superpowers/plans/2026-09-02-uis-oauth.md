# 复旦 UIS OAuth 认证 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 Vue 3 + FastAPI 应用中实现后端托管的复旦 UIS OAuth 登录、本地会话、访问控制和完整自动化测试。

**Architecture:** FastAPI 作为机密 OAuth 客户端处理授权码、Token 与 UserInfo，并使用签名 `HttpOnly` Cookie 保存最小本地会话。Vue 仅查询本地会话、呈现登录门禁，并让所有业务请求携带 Cookie；四组业务 router 在聚合层统一施加鉴权依赖。

**Tech Stack:** Python 3.10+、FastAPI、Starlette SessionMiddleware、httpx、Pydantic、pytest；Vue 3、TypeScript、Vite、Vitest、Tailwind CSS。

**Spec:** `docs/superpowers/specs/2026-09-02-uis-oauth-design.md`

## Global Constraints

- 工作必须直接位于现有 `dev` 分支，不创建或切换其他分支。
- 不把真实 `client_id`、`client_secret`、会话密钥、授权码或 Token 写入 Git、前端变量或日志。
- 不启用 PKCE。
- Token 请求表单只有 `grant_type` 和 `code`，不包含 `redirect_uri`。
- UserInfo 只接受 3.2.3.6 的 snake_case 字段及 `sessionId`。
- `user_type == "本专科生"` 必须拒绝登录。
- 回调地址固定为 `https://lushangstudio.fudan.edu.cn/api/auth/callback`，代码不接受请求参数覆盖。
- 不实现尚未给出数值和周期的单用户配额功能。
